**Q：登录上去显示“账号已被锁定”或者“出于安全原因禁用”？**  
公共号一天几千人登，异地IP太多触发苹果风控是常态。看到这个别点“解锁”（点了要发邮件验证码），直接退出来换页面上的其他备用号，或者去 [TG群](https://t.me/kjdidcom) 喊管理员解封。更多经验也可以看 [苹果ID踩坑文章汇总](https://blog.aimaihao.com/category/category/apple-id/)。

**Q：以后更新软件的时候，怎么老提示要输密码？**  
iOS 的逻辑是：用哪个号下的 App，更新时就得用那个号的密码。共享号密码经常换，所以**建议软件下好后别频繁更新**。如果是非更新不可的软件，删了用当时最新的共享号重下，或者干脆搞个独享号。

**Q：登录时跳出来要绑定手机号/双重验证？**  
千千万万别填你自己的手机号！点击弹窗下面的“其他选项”，再选“不升级”就能跳过去。直接绑手机号不仅害了别人，你自己以后也解不开。
